Your quick reference

Payoff matrixFirst number = row player; second = column player. Compare the row player's payoffs vertically and the column player's horizontally.
Nash equilibriumNo player benefits by changing their own strategy alone. Find cells that are best responses for both players.
DominanceA strictly dominant action is better against every possible opponent action. Check every comparison.
Sequential gameStart at the last decision. Choose what that player actually prefers, then work backward. Test threats after the triggering event.
MonopolyFor P = a − bQ, MR = a − 2bQ. Find Q using MR = MC; find P using demand. Profit = revenue − total cost.
Price customizationIdentify groups or self-selection; check resale. With the same MC, less elastic demand supports a higher optimal markup: (P − MC)/P = 1/|ε|.
Repeated interactionFuture punishment can support cooperation if it is credible and the future matters enough. A known finite prisoners' dilemma has different incentives.
